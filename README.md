# Scientific Computing

MATLAB coursework from Numerical Analysis II / Scientific Computing with Dr. Tulin Kaman at the University of Arkansas.

## Assignment map

- `Homework2/` — bisection, fixed-point iteration, Newton's method, and the secant method
- `Homework4/` — compressed-column sparse storage and multiplication
- `Homework5/` — least-squares fitting, modified Gram-Schmidt, and QR-related results

Start MATLAB in the repository root and add the relevant homework folder to the path before running a script.

```matlab
addpath("Homework5")
question3
```

Figures and PDFs are retained as assignment results. These files document completed coursework; reuse should follow the repository license and your institution's academic-integrity policy.
